# كاشير باركود أوفلاين — الماسح الهجين v1.1.0

تطبيق Flutter للكاشير والمخزون يعمل بدون إنترنت، مع نظام قراءة باركود متعدد الطبقات حتى لا يتوقف العمل إذا فشلت إحدى طرق الكاميرا على جهاز معين.

## طرق قراءة الباركود

### 1. المسح المباشر — الوضع الأساسي

- يعرض الكاميرا داخل التطبيق ويقرأ الباركود فورًا.
- إطار مركزي لتوجيه الباركود.
- تركيز باللمس وتكبير تلقائي على Android.
- تشغيل وإطفاء الفلاش.
- صوت واهتزاز عند نجاح القراءة.
- منع تكرار نفس القراءة بسبب استمرار الكاميرا.
- إدارة إيقاف وتشغيل الكاميرا عند انتقال التطبيق للخلفية.

### 2. كاميرا النظام — الوضع الاحتياطي

إذا لم تعمل الكاميرا المباشرة على جهاز معين، يمكن التقاط صورة بواسطة تطبيق كاميرا الهاتف ثم تحليل الباركود من الصورة.

### 3. الإدخال اليدوي أو قارئ خارجي

نافذة الإدخال تقبل الأرقام والحروف، ويمكن استخدامها مع قارئ باركود USB أو Bluetooth يعمل كلوحة مفاتيح. اضغط Enter بعد المسح لاعتماد الرمز مباشرة.

## صيغ الباركود المدعومة

- EAN-13 وEAN-8
- UPC-A وUPC-E
- Code 128 وCode 39 وCode 93
- ITF وCodabar
- QR Code وData Matrix

## تحسينات الثبات

- لا يتم تشغيل الكاميرا مرتين في الوقت نفسه.
- إيقاف الكاميرا قبل فتح كاميرا النظام أو نافذة الإدخال.
- إعادة تشغيل المسح المباشر عند الرجوع دون نتيجة.
- رسائل عربية واضحة عند رفض إذن الكاميرا أو عدم دعم الجهاز.
- تحويل الأرقام العربية والفارسية إلى أرقام إنجليزية قبل البحث عن المنتج.
- حذف صورة الالتقاط المؤقتة بعد التحليل قدر الإمكان.

## بقية الميزات

- إدارة المنتجات والكميات والأسعار.
- البيع بالباركود وخصم المخزون.
- حفظ الفواتير والتقارير محليًا.
- مشاركة نص الفاتورة.
- العمل بدون خادم أو حساب أو اتصال بالإنترنت.

## بناء APK عبر GitHub Actions

يفحص مسار البناء:

1. أخطاء Dart بواسطة `flutter analyze`.
2. اختبارات تطبيع الباركود بواسطة `flutter test`.
3. بناء APK إصدار Release.
4. رفع الملف باسم:

```text
offline-barcode-cashier-robust-scanner.apk
```

## اختبار الماسح بعد تثبيت APK

1. افتح شاشة البيع واضغط **مسح للبيع**.
2. وافق على إذن الكاميرا.
3. جرّب باركود EAN-13 واضحًا وفي إضاءة جيدة.
4. جرّب الفلاش في الإضاءة الضعيفة.
5. أغلق شاشة المسح وافتحها مرة أخرى للتأكد من عودة الكاميرا.
6. جرّب زر **كاميرا النظام** إذا لم يعمل العرض المباشر.
7. جرّب قارئ USB أو Bluetooth من زر **يدوي / خارجي**.

## ملاحظة مهمة

نجاح المسح يعتمد أيضًا على جودة كاميرا الجهاز، التركيز، الإضاءة، حجم الباركود وسلامة الطباعة. وجود الطرق الثلاث يضمن استمرار العمل حتى عندما تكون إحدى طرق الكاميرا غير متوافقة مع جهاز محدد.
