# كاشير باركود أوفلاين - نسخة كاميرا النظام v1.0.16

هذه نسخة مستقرة للأجهزة الحديثة لا تستخدم mobile_scanner ولا qr_code_scanner.
تفتح كاميرا النظام لالتقاط صورة للباركود ثم تقرأه عبر Google ML Kit.

الهدف: تجاوز أخطاء MobileScannerErrorCode.genericError وأخطاء CameraX الداخلية.

الميزات:
- كاشير ومخزون أوفلاين.
- إدخال/قراءة الباركود عبر كاميرا النظام.
- إدخال يدوي احتياطي.
- حفظ المنتجات والفواتير والتقارير محليًا.
- GitHub Actions لإخراج APK.
