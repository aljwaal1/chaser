# كاشير باركود أوفلاين

تطبيق كاشير ومخزون يعمل بدون إنترنت، مع إضافة وبيع المنتجات عبر مسح الباركود.

## الأقسام
- الرئيسية
- المنتجات
- بيع جديد بالباركود
- الفواتير
- التقارير

## المزايا
- تخزين المنتجات محليًا.
- مسح باركود بالكاميرا.
- إضافة صنف جديد عبر الباركود.
- البيع بالباركود.
- خصم تلقائي من المخزون.
- فاتورة نصية قابلة للمشاركة.
- تقرير يومي بسيط.
- لا يحتاج إنترنت أو حساب.

Actions -> Build Android APK -> Run workflow
